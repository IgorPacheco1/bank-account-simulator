# Bank Account Simulator

O **Bank Account Simulator** é uma aplicação de console desenvolvida em Java que simula as operações básicas de uma conta bancária. O sistema permite consultar o saldo disponível, realizar depósitos, efetuar transferências e atualizar as informações da conta de acordo com cada operação realizada.

A aplicação funciona por meio de um menu interativo no terminal, onde o usuário pode selecionar as operações desejadas. O sistema também realiza validações simples, como impedir transferências quando o saldo disponível é insuficiente e informar quando uma opção inválida é selecionada.

Este projeto representa uma implementação simples de um sistema bancário, utilizando apenas recursos básicos da linguagem Java e interação via linha de comando.
